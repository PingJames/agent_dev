# Project Context: AI 应用工程师路线图

## 项目概述
一个学习平台，帮助开发者成长为 AI 应用工程师。提供清晰的学习路线图、博客教程、项目实战和面试题库。

## 技术栈
- **前端框架**: Next.js 14 (App Router)
- **语言**: TypeScript
- **CSS**: TailwindCSS
- **UI 组件**: Shadcn UI
- **内容**: MDX (next-mdx-remote)
- **搜索**: fuse.js
- **部署**: Vercel / 静态导出

## 目标用户
1. 初级前端/后端开发者，想转型 AI 应用开发
2. 有编程基础的学生或自学开发者
3. 对 AI Agent、RAG、LLM 应用感兴趣的工程师

## 核心功能
1. 交互式学习路线图
2. MDX 驱动的博客系统
3. 项目实战展示
4. 面试题库
5. 搜索功能
6. SEO 优化

## 设计原则
- 内容优先：MDX 内容与代码分离
- 性能至上：SSG + ISR 策略
- 渐进增强：基础 HTML 可访问，JavaScript 增强交互
- 移动优先：响应式设计

## 配色方案
- 主色: Indigo-600 (#4F46E5)
- 辅助色: Purple-500 (#8B5CF6)
- 成功: Emerald-500 (#10B981)
- 警告: Amber-500 (#F59E0B)
- 错误: Red-500 (#EF4444)
- 背景: Slate-50 (#F8FAFC) / Slate-900 (#0F172A) 暗色
