# Prompt Engineering Guide

## 用于 AI 辅助开发的提示词模板

### 代码生成
```
请帮我实现 [功能描述]。
要求：
- 使用 Next.js 14 App Router + TypeScript
- 遵循项目 coding-rules.md
- 添加完整的类型定义
- 包含错误处理和加载状态
- 添加必要的注释
```

### 组件开发
```
请创建 [组件名] 组件。
Props 接口：[描述]
功能需求：[列表]
UI 参考：[描述或链接]
按照项目的 UI guidelines 实现。
```

### 代码审查
```
请审查以下代码：
- 是否符合项目编码规范
- 是否有性能问题
- 是否有安全隐患
- 是否可优化
```

### Bug 修复
```
遇到以下问题：[描述]
期望行为：[描述]
实际行为：[描述]
相关错误信息：[粘贴]
项目技术栈：Next.js 14 + TypeScript + TailwindCSS
```

### 内容创作
```
请为 [主题] 创建一篇技术博客文章。
目标读者：[描述]
文章结构：
1. 引言（问题背景）
2. 核心内容（技术实现）
3. 代码示例
4. 最佳实践
5. 总结
格式：MDX（支持 React 组件嵌入）
```

## AI 协作最佳实践
1. 提供充分的上下文（项目结构、技术栈、现有代码）
2. 明确期望的输出格式
3. 分步骤执行复杂任务
4. 及时反馈和迭代
5. 保持项目文档同步更新
