## 问题

请解释 Transformer 架构中的自注意力机制（Self-Attention），包括其计算过程和相对于 RNN 的优势。

## 参考答案

### Self-Attention 的核心思想

Self-Attention 允许模型在处理每个位置时，直接关注输入序列中所有其他位置的信息，而不仅仅是局部信息。

### 计算过程

```text
给定输入序列 X ∈ R^(n×d)

1. 计算 Q、K、V：
   Q = X·Wq    Query（查询）：我要找什么
   K = X·Wk    Key（键）：我有什么
   V = X·Wv    Value（值）：我的内容

2. 计算注意力分数：
   Attention(Q, K, V) = softmax(Q·K^T / √d_k) · V
```

### Python 实现

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    Q, K, V: (batch, seq_len, d_model)
    """
    d_k = K.size(-1)

    # Q · K^T / √d_k
    scores = torch.matmul(Q, K.transpose(-2, -1)) / torch.sqrt(d_k)

    # 掩码（用于 decoder）
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))

    # Softmax
    attention_weights = F.softmax(scores, dim=-1)

    # 加权求和
    output = torch.matmul(attention_weights, V)

    return output, attention_weights
```

### 相对于 RNN 的优势

1. **并行计算**：所有位置同时计算，无序列依赖
2. **长距离依赖**：直接建模任意距离的依赖关系
3. **可解释性**：通过注意力权重可视化分析
