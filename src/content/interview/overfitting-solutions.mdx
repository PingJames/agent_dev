## 问题

请解释过拟合（Overfitting）的概念、成因以及解决方法。

## 参考答案

### 什么是过拟合？

过拟合是指模型在训练数据上表现很好，但在新数据（测试集）上表现很差的现象。模型"记住"了训练数据中的噪声和细节，而不是学习到真正的底层规律。

```text
        训练误差        测试误差
好的拟合： 低    →       低
欠拟合：   高    →       高
过拟合：   很低  →       高（模型死记硬背）
```

### 过拟合的原因

1. **模型复杂度过高**：参数过多，远超数据量
2. **训练数据不足**：样本量太少，无法代表真实分布
3. **数据噪声**：训练数据包含大量噪声
4. **训练时间过长**：深度学习场景下 epoch 过多

### 解决方法

#### 1. 正则化（Regularization）

```python
# L1 正则化（Lasso）
# 产生稀疏解，可用于特征选择
loss = mse + λ * Σ|wᵢ|

# L2 正则化（Ridge）
# 使权重趋于小值但不为零
loss = mse + λ * Σ(wᵢ²)
```

#### 2. Dropout

```python
import torch.nn as nn

class Model(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(768, 256),
            nn.ReLU(),
            nn.Dropout(p=0.3),  # 随机丢弃 30% 神经元
            nn.Linear(256, 10)
        )
```

#### 3. 早停法（Early Stopping）

在验证集误差不再下降时停止训练。

#### 4. 数据增强

- 图像：旋转、翻转、裁剪、色彩变换
- 文本：回译、同义词替换、随机删除

#### 5. 集成学习

- Bagging（如随机森林）：训练多个模型，投票/平均
- Boosting（如 XGBoost）：级联训练，关注之前分错的样本

### 偏差-方差权衡

过拟合本质上是**高方差**问题。解决方案是增加偏差（bias）来减少方差：

- **偏差高**（欠拟合）→ 增加模型复杂度
- **方差高**（过拟合）→ 降低模型复杂度或增加数据量
