## 项目概述

构建一个完整的企业级文档智能问答系统，核心功能包括：

- 支持多种文档格式上传（PDF、DOCX、TXT、Markdown）

## 核心实现

### 文档处理模块

```python
from langchain.document_loaders import (
    PyPDFLoader,
    Docx2txtLoader,
    TextLoader,
    UnstructuredMarkdownLoader
)

class DocumentProcessor:
    LOADERS = {
        ".pdf": PyPDFLoader,
        ".docx": Docx2txtLoader,
        ".txt": TextLoader,
        ".md": UnstructuredMarkdownLoader,
    }

    @staticmethod
    def load(file_path: str):
        ext = Path(file_path).suffix.lower()
        loader_cls = DocumentProcessor.LOADERS.get(ext)
        if not loader_cls:
            raise ValueError(f"不支持的文件格式: {ext}")
        loader = loader_cls(file_path)
        return loader.load()
```
